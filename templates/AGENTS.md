# AGENTS.md — инструкции для агентов клетки <имя>

Клетка живёт по пяти законам роя (README.md ядра cell-swarm, docs/adr/).

## Порядок чтения

1. `README.md` — вход и быстрый старт.
2. `MANIFEST.json` — ДНК клетки.
3. `docs/adr/` — решения клетки (если уже есть).

## Правила

1. Пин этой клетки хранится в геноме ядра (`cell-swarm/swarm.json`) — обновляй
   через `make pins` в ядре, пин «по памяти» не вносится.
2. Поведение меняется — сначала ADR в `docs/adr/`, потом код (храповик).
3. Тесты только добавляются.
4. Офлайн-first: клетка запускается без сети и без обязательных SaaS.
5. Секреты не коммитятся; токены — только env.
6. Обмен с другими клетками — через геном ядра (пины), не через импорты.
