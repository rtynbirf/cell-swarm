# AGENTS.md — инструкции для агентов роя

Рой ведётся Человеком и агентами. Агенты — полноценные работники роя; на них
распространяются те же пять законов (README.md, docs/adr/).

## Порядок чтения

1. `README.md` — вход, пять законов, словарь.
2. `MANIFEST.json` — ДНК ядра роя.
3. `swarm.json` — геном: клетки, пины, мост в дом COMMONS.
4. `docs/adr/` — журнал решений (почему так).
5. `peers/peer-manifest.json` и `consent/grants.json` — голос и согласия роя.
6. `tests/test_swarm.py` — живые приёмки всех грамматик.
7. Если память стёрта (песочница обновилась): сначала `sandbox/MEMORY.md` —
   твой нуль, затем `sandbox/STATE.json` — где прервался предыдущий экземпляр.

## Правила работы

1. **Геном — источник истины.** Правка состава/пинов клетки — правка `swarm.json`
   с датой и методом получения SHA; код и bootstrap следуют за геномом.
2. **Клетки не форкать** (Закон 3): пины указывают на upstream; клетки Человека
   — сами upstream. Дом COMMONS не форкается никогда.
3. **Обмен с домом — только по согласию обеих сторон** (ADR-0017 дома,
   зеркальная грамматика в `scripts/handshake.py`): вердикт до факта, белый
   список методов, поимённый отказ. Незаявленный метод — `denied(method_not_in_scope)`.
4. **Кровь с ценой** (`scripts/emit.py`, SPEC-0003 дома): событие без cost
   недействительно; тип — только из словаря дома; журнал append-only,
   хэш-цепочка `prev_id`/`prev_sha256` (каноническая форма дома — совместима байт-в-байт).
5. **Офлайн-first**: ядро работает без сети и без обязательных SaaS;
   живой `git ls-remote`/GitHub API — только для обновления пинов и лицензий,
   результат всегда с датой.
6. **Храповик**: тесты и ADR только добавляются; изменение поведения — сначала
   ADR в `docs/adr/`, потом код.
7. Коммиты — Conventional Commits; вклад в дом — только DCO (`git commit -s`).
8. **Секреты не коммитятся никогда**; токены — только env/файл 0600, в кровь не попадают.
9. **Событийная сверка генома (TH-RTP-04):** пуш клетки в main сам сообщает
   геному (repository_dispatch «cell-pushed» из её метаболизма →
   `.github/workflows/genome-reconcile.yml`) — пин догоняется живым ls-remote
   по факту события, не по времени и не по накоплению; без события сверка
   не запускается; ручная — `make pins` / workflow_dispatch.
10. Чужие код, тексты и медиа не вносятся ни под какой лицензией — клетки входят
   в геном как пины, имена и верифицированные факты.
11. **Прививка памяти (ADR-0007):** перед смертью сеанса агент зеркалит состояние
    в `sandbox/` — пополняет `MEMORY.md` (нуль) и `sandbox/STATE.json` (точка
    прерывания), копирует рабочие скрипты в `sandbox/scripts/`. Конспект
    только пополняется; забвение — тип `forget` в крови, не правка нуля.

## Грабли и золотая середина

Перед операциями прочти доктрину ошибок роя: `rtynbirf/repo-doctrine`,
файл `20-грабли-и-золотая-середина-агентов-2026-11-09.md` — 40 реальных событий
(Событие → Корень → Правило) и 10 законов золотой середины; чек-лист «10 касаний»
прогоняется перед каждым действием. Для генома особенно: грабля №38 (перед патчем
— свежий head, перевешивание поверх head, append-only) и №40 (манифест/генерат
собирается ПОСЛЕ `git add` нового файла — «локально зелёный» до стейджа не считается).

## Запрещено агентам

- Обход согласия: любой обмен с домом мимо `handshake.py`.
- Пины «по памяти»: SHA без живого источника и даты не вносится.
- Правка крови задним числом: журнал append-only, забвение — тип `forget`.
- Расширение transports за `stdio`/`http-localhost`: наружного шлюза нет (ADR-0016 дома).
