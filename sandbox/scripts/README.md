# Зеркало рабочих скриптов песочницы

Сюда агент кладёт копии скриптов, которыми реально работал в песочнице
(поставки, проверки, клонирование). Песочница умирает — зеркало остаётся.

- `fetch_rtynbirf.sh` — снимок состояния GitHub владельца на дату: HEAD дома,
  ветки, PR, теги, пины клеток роя (ls-remote). Запуск: `bash fetch_rtynbirf.sh`.
