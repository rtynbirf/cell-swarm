# Память роя = файлы с допуском

Каждая строка знания — файл `MEM-*.json` с **двумя допусками** (волна ×9,
2026-11-09):

| Допуск | Поле | Что ограничивает |
|---|---|---|
| Время | `tol.ttl_days` | сколько живёт знание: `verified_at + ttl >= сегодня`, иначе ДРЕЙФ |
| Доступ | `acl` | кто вправе читать: `level: public \| cell \| swarm` + `owner_cell` (клетка генома, обязательна при `level != public`) + `reason` (почему такой допуск, обязателен всегда) |

Оба допуска входят в хеш-цепь памяти (`prev`/`hash`, GENESIS = 64 нуля):
подмена допуска ловится той же тампер-очевидностью, что и подмена знания.

Уровни доступа:

- **public** — весь рой и мир (репо публично, скрывать нечего);
- **cell** — только клетка-владелец (`owner_cell`): внутренний такт тела;
- **swarm** — только рой: знание до публикации миру.

Страж — `tools/memory_check.py` (проверка 4 ДОПУСК, fail-closed):
допуск без причины, неизвестный уровень или `owner_cell` вне генома —
это РАНА, память с раной не принимается (`make memory` → exit 1).

Приёмка — `tests/test_memory_acl.py` (9 кейсов + живая цепь).
