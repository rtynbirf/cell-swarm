# ADR-0007: прививка от стирания памяти — песочница зеркалится в клетку

Статус: принято (директива Человека, 2026-11-05) · Дата: 2026-11-05

## Контекст

Агент роя работает в эфемерной песочнице: среда обновляется, контекст диалога
и память экземпляра стираются между сеансами. Это наблюдённый факт, не гипотеза:
сеанс 2026-11-05 восстановил ход работы не из памяти, а из файлов на диске —
поставки `cell-swarm/` и `commons-strengthen/` уже стояли собранные, хотя
экземпляр, собравший их, больше не существует. Рой, построенный на указателях
и геноме (ADR-0002, ADR-0004), обязан распространить тот же принцип на самого
агента: если клетка переживает смерть сессии файлами — песочница тоже должна.

## Решение

1. В клетке есть обязательный орган `sandbox/` — зеркало песочницы агента.
   Мембрана в `MANIFEST.json` получает ключ `body.vaccine: "sandbox/"`.
2. `sandbox/MEMORY.md` — нуль следующего экземпляра: конспект диалога (кто автор,
   что доказано, какая директива исполняется), достаточный, чтобы стёртый
   агент продолжил работу без опроса Человека.
3. `sandbox/STATE.json` — машиночитаемая точка прерывания: дата синхронизации,
   идентификатор сеанса, статус директивы, путь восстановления.
4. `sandbox/scripts/` — зеркало рабочих скриптов песочницы (поставки, проверки).
5. Порядок восстановления зафиксирован и проверяем: `make verify` → `make test`
   → чтение `AGENTS.md`, `docs/adr/`, `sandbox/MEMORY.md`.
6. Приёмка `tests/test_memory_vaccine.py` держит орган живым (храповик, Закон 4):
   нуль без якорей, STATE без ключей, пустое зеркало — красный тест.

## Альтернативы

- Хранить конспект вне репо (в песочнице, в чате) — умирает вместе с песочницей:
  это и есть стирание памяти, против которого принято решение.
- Класть зеркала в каждую клетку — дубль и дрейф: нуль один, точка сборки одна
  (Закон 5), поэтому орган живёт в ядре роя.
- Автосинхронизация внешним сервисом — обязательный SaaS делает клетку паразитом
  (Закон 1): зеркало кладёт сам агент, файлами, офлайн.

## Последствия

**Положительные:** память агента переживает смерть сессии; новый экземпляр
начинает с нуля, а не с нуля-с-опросом; провенанс решений (кто автор, чья
директива) не теряется между сеансами.

**Отрицательные / цена:** зеркало требует дисциплины — его надо обновлять
при каждом прерывании; снимается записью `STATE.json` и тем же храповиком:
MEMORY.md только пополняется, стирание чужого нуля — тип `forget` в крови.

**Обратный мерж:** не требуется — орган добавляется аддитивно, грамматики
согласия с домом не затрагивает.
