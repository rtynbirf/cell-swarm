# ADR-0015: Песочница ρ-Governor — dry-run валидация гипотез H1–H3

- **Статус:** принято (волна TH-SG-2, 2026-11-10)
- **Участники:** рой cell-swarm; спека — nous (`docs/genesis/semantic-governor.md` §6)
- **Связано:** ADR-0014 (GENESIS_EXEC в рое, dry-run по умолчанию), ADR-0002
  (указатели, не импорты), ADR-0003 (offline-first)

## Контекст

Спека ρ-Governor v0.1 (nous, PR #25) вводит три убиваемые гипотезы валидации
(H1 безвредность, H2 κ-детектор, H3 свежесть semantic_state) и требует
песочницы роя до любого выхода из dry-run. Пин между домами — по Законам роя:
указатели и SHA, не копии контента.

## Решение

1. Принять `sandbox/governor-h123/` как сухой контур валидации: симуляция
   фуражировки с подсадным картелем; валидируется математика губернатора
   (κ-детектор HHI, VENT, pass^3, MAST-прокси), не поведение LLM.
2. Офлайн-first: только stdlib, сеть не нужна (ADR-0003); приёмка в CI —
   `tests/test_governor_sandbox.py` (8 тестов, < 1 с), кампания — по событию
   волны, не по расписанию.
3. Вердикты кампании 2026-11-10 (100 сидов × 3 руки × 3 реплики) зафиксированы
   в `sandbox/governor-h123/README.md`: H1 подтверждена (+7.2 п.п. утилизации,
   pass³ 0.43→0.74), H2 подтверждена по официальному критерию (−32.5% ≥ −20%)
   с честным распределением по сидам (58% сидов ≥ цели), H3 подтверждена
   механически (fail-closed 8/8). v0.2-гистерезис хуже v0.1 и не принимается.
4. Губернатор НЕ выходит из dry-run: песочница даёт числа, живые действия —
   только вердикт PID 1 (ADR-0014). Разбор миров с p25 < 0 (где remedy не
   окупается) — отдельная волна до любых полномочий.

## Альтернативы

- LLM-в-контуре сразу: дорого, недетерминированно, не воспроизводимо в CI —
  отложено; правило-агенты дают чистую проверку математики.
- Жить без песочницы: спека, которую нельзя опровергнуть, — Σ-акт без Δ;
  отвергнуто по канону убиваемых гипотез.

## Последствия

- Геном, grants, мембрана не тронуты; новый файл приёмки добавляется к
  стандартному unittest-дискавери.
- Сим-порог κ (0.35) ≠ канон дома (0.5): отклонение задокументировано в README
  (размер роя), формула та же.
- Каждая будущая политика VENT обязана пройти эту песочницу с константами,
  объявленными до прогона, и с распределением по сидам в отчёте.
