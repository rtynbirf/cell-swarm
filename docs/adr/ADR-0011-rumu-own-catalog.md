# ADR-0011: свой каталог РУМУ — вариант (в) ADR-0008 исполнен

Статус: принято (воля PID 1, 2026-11-05: «вариант (а)/(в) — НЕ МНЕ А ТЕБЕ.
И БЕЗ ВАРИАНТОВ. ТЫ ПОЛИМАТ=МУЛЬТИАГЕНТ ВСЕГДА ДЕЙСТВУЕШЬ ИЗ ВНОВЬ
ОТКРЫВШИХСЯ ОБСТОЯТЕЛЬСТВ СОГЛАСНО ЛОГИКЕ») · Дата: 2026-11-05

## Контекст

ADR-0008 (fail-closed): открытой лицензии на каталог источника нет.
ADR-0009: зеркало облегчено до фактов — вариант (б); открытыми остались
(а) письменное разрешение источника и (в) свой каталог — оба ждали
владельца. Новые обстоятельства такта 2026-11-05:

1. Владелец передал выбор рою, без возврата варианта.
2. Вариант (а) по устройству требует чужой воли (письмо правообладателя) —
   рой его исполнить не может, а зависимость «ждём чужого разрешения»
   противоречит логике автономии роя и Законам 1/5 (клетка живёт своей
   мембраной, семя возрождается офлайн).
3. Осмотр ветки rumu (живой клон) показал: у плеера уже есть СВОЙ каталог —
   встроенный JSON в cinema.html/kino.html/streaming.html (ЛАКОРНИЯ,
   builtAt 2026-10-20, ~35 тайтлов, свои описания и ссылки на эпизоды);
   зеркальный catalog.js обслуживает только title.html, связка id между
   двумя системами не согласована. Путь (в) фактически уже начат самим
   владельцем — рою оставалось довести его до конца.

## Решение

Вариант (в): каталог РУМУ — собственный. Исполнено в ветке
singulyar@rumu-own-catalog (коммит 3c551e8, DCO):

- `catalog.js`: поле внешнего id снято, своя нумерация `i: 1..249`
  (порядок записей сохранён — храповик); шапка — лицензия CC0 1.0 и
  честное происхождение начального среза (факты из облегчённого до
  фактов состояния варианта «б»; факты авторским правом не охраняются,
  всё охраняемое снято ещё в ADR-0009);
- `title.html`: бейджи источника («Бесплатно/Premium на bldub») заменены
  собственным статусом каталога (онгоинг/вышел/скоро);
- рост каталога: открытые источники (Wikidata — CC0; TVmaze — CC BY-SA,
  с атрибуцией) и владелец (PID 1).

Проверки: 249/249 записей перенумерованы; вхождений строки источника —
ноль в обоих файлах; `node --check` — OK; `title.html` — единственный
потребитель catalog.js (проверено перебором файлов ветки).

## Следствия

- РУМУ не зависит ни от одной внешней базы: ни данных, ни id, ни статусов.
- Вопрос (а)/(в) закрыт; вариант (а) не требуется; при изменении воли
  владельца полное зеркало восстанавливается из истории git (храповик).
- Риск «титулы ссылаются на источник без лицензии» (остаток ADR-0009)
  снят: ссылок на источник больше нет ни в данных, ни в UI.
- Пин тела РУМУ в геноме обновляется после слияния ветки в singulyar@rumu
  (`make pins`).
