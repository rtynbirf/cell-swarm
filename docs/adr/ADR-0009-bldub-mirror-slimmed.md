# ADR-0009: зеркало bldub облегчено — вариант (б) ADR-0008 исполнен

Статус: принято (исполнено роем по прямому поручению владельца) · Дата: 2026-11-05

## Контекст

ADR-0008 зафиксировал fail-closed: открытой лицензии на каталог bldub нет
(живая проверка веба 2026-11-05), зеркало `catalog.js` (249 тайтлов: названия,
описания, рейтинги, хотлинк постеров на bldub.com) лежит в публичном
singulyar@rumu; выбор из трёх вариантов — за Человеком (PID 1).

2026-11-05 (сеанс web-04b56e42) владелец ответил по всем открытым пунктам:
«ПО ЭТИМ ПУНКТАМ ТОЖЕ ИНСТРУКЦИЮ ИЛИ ДЕЛАЙ САМ КАК СЧИТАЕШЬ НУЖНЫМ, ЧТОБ НЕ
ИМЕТЬ ТРЕНИЙ И КОНФЛИКТОВ С КЕМ ЛИБО». Из трёх вариантов (б) — единственный,
который (1) исполним роем целиком, без руки человека; (2) прямо снижает
трение с правообладателями; (3) обратим чтением истории git.

## Решение

`catalog.js` в singulyar@rumu облегчен до фактов (коммит b389ac91, 2026-11-05):

- остались: `bldub_id` (id), `t`/`orig` (названия), `cat`, `y`, `country`,
  `eps`, `status`, `genres` (факты о произведении), `q` (ключ поиска —
  плеер опирается на него в навигации/поиске);
- сняты: `description` (скопированный текст источника), `image` (хотлинк
  bldub.com), `rating`/`votes` (агрегаты их БД), `premium` (их коммерческий
  флаг), `e` (декоративный эмодзи их листинга);
- все 249 записей сохранены; 232 КБ → 79 КБ; проверено: `node --check`,
  самопроверка `scripts/slim_catalog.py` (запрещённых полей нет, каждый id
  и название на месте; вхождений строки «bldub.com» — ноль).

## Последствия

- Плеер: карточки без постеров/описаний и бейджей premium/рейтинга;
  навигация (категория/год/страна/эпизоды/жанры) и поиск работают.
- Полный до-облегчённый вид — история git (коммит до b389ac91): при варианте
  (а) — письменном разрешении bldub — зеркало восстанавливается из истории
  одной командой; при варианте (в) — свой каталог строится рядом.
- Варианты (а) и (в) остаются открытыми за Человеком. ADR-0008 не отменяется —
  исполняется частично (храповик: только добавляется).
- Юрисдикция по-прежнему не предполагается (правило автора): это минимизация
  объёма заимствуемого, не правовая оценка.
