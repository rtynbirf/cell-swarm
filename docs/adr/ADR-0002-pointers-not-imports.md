# ADR-0002: связь указателями, не импортами

Статус: принято · Дата: 2026-11-05

## Контекст

Клетки должны обмениваться, не срастаясь. Субмодули и внутренние пакеты сшивают
истории git в один коммит-граф — клетка теряет автономность. Принцип трекера
(разобран до разговора об архитектуре): хаб хранит указатели (магниты), не контент.

## Решение

Клетки связаны пинами — SHA коммитов в геноме `swarm.json`, с датой и методом
получения. Геном хранит магниты, не код. Обновление клетки = один SHA.
Пин «по памяти» не вносится: только живой `git ls-remote` с датой.

## Альтернативы

- git submodules — сшитые истории, ад обновлений, чужой workflow.
- Мультирепо-пакеты (npm/pip) — нужен реестр и публикация: SaaS-зависимость,
  против автономности клетки.

## Последствия

**Положительные:** клетки обновляются независимо; геном — дифф из одного символа;
клон клетки работает без всего роя.
**Отрицательные / цена:** нет атомарных кросс-изменений; пины нужно обновлять руками
(`make pins`) — принимается.

## Проверяемость

`bootstrap.sh` поднимает рой на чистой машине; если сборка роя требует
рукопашной правки чужого кода — закон нарушен.
