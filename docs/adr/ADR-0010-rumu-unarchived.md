# ADR-0010: rumu разблокирован, мембрана клетки влита в main

Статус: принято (исполнено роем по прямому поручению владельца) · Дата: 2026-11-05

## Контекст

Клетка `rumu` — держатель имени: тело живёт веткой `rumu` в singulyar
(пин b389ac91, сверка живым ls-remote 2026-11-05), сам репо был архивен
(read-only), мембранная ветка `membrane-2026-11-05` ждала локально. ROADMAP
предлагал владельцу выбор: разморозка (пуш мембраны) или жизнь имени через
пин генома.

2026-11-05 владелец спросил «КАК ЭТО СДЕЛАТЬ? ДАЙ ИНСТРУКЦИЮ?» и передал
рою право действовать самому по всем открытым пунктам («делай сам как
считаешь нужным, чтоб не иметь трений и конфликтов с кем либо»). Разморозка
исполнима роем целиком (API-вызов + пуш), пин-вариант действий не требует;
выбрана разморозка — Закон 1/2 (мембрана в репо клетки) исполняется до конца.

## Решение

1. `PATCH /repos/rtynbirf/rumu {"archived": false}` — репо разблокирован
   (HTTP 200, 2026-11-05). Откат: тот же вызов с `{"archived": true}`.
2. Мембранная ветка пересобрана (клеточные клоны песочницы потеряны при
   перезапуске среды; содержание то же, что в локальной сборке: AGENTS.md +
   MANIFEST.json + llms.txt, клетка-указатель) и влита PR#1 → main.
3. Срезы пина тела в мембранных файлах обновлены следом за телом (тело ушло
   на b389ac91 в тот же такт — облегчение каталога, ADR-0009): 7512768,
   2896722, 0df9754. Живой пин — геном ядра (`make pins`); клеточные копии —
   сверенные срезы на дату, геном старше их.
4. Пин клетки в геноме обновлён живой сверкой (такт 2026-11-05, геном 0.1.3).

## Последствия

- Клетка полноправная по Закону 1: имя + мембрана в своём репо, тело — по
  указателю (Закон 3). Никакой части роя больше не нужен отдельный лист
  ожидания для rumu.
- Dependabot может проснуться в разблокированном репо — рутинные волны
  принимаются по храповику, как в остальных клетках.
- Перенос тела из ветки singulyar@rumu в самостоятельный репозиторий —
  по-прежнему отдельный такт за владельцем (README клетки).
- Команды повтора/отката записаны в DEPLOY.md ядра (раздел про разблокировку).
