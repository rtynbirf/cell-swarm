# ADR-0001: граница репозитория = граница контекста

Статус: принято · Дата: 2026-11-05

## Контекст

Классический закон Конвея: организация отражается в архитектуре. Для роя из одного
человека и N агентов организационной схемы нет — есть память: рабочая память человека
и окно контекста агента. Структура, которую нельзя удержать в одной сессии, не
работает ни для кого.

## Решение

Граница репозитория проводится по границе контекста: клетка — то, что агент и человек
способны держать в голове за одну сессию. Митоз — по боли контекста (агент теряет нить,
человек забывает, где что): файл → папка → репо. Не делить до боли; не сливать без нужды.

## Альтернативы

- Монорепо-всё — атомарность, но окно контекста не резиновое: поиск внутри растёт,
  агент платит за весь дом каждый раз.
- Репо на каждый чих — цена обнаружения: геном без клеток пуст.

## Последствия

**Положительные:** каждая клетка влезает в голову; границы стабильны, потому что
растут из употребления, а не из плана.
**Отрицательные / цена:** кросс-клеточные изменения не атомарны — лечится геномом
пинов; версии дублируются.

## Проверяемость

Через полгода: если какая-то клетка регулярно требует «держать в голове» вторую —
граница проведена неправильно, митоз. Метрика — число сессий, где понадобились
две клетки сразу.
