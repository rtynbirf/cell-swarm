# ADR-0005: одна броня — Apache-2.0, донорство по рукопожатию

Статус: принято · Дата: 2026-11-05

## Контекст

Иммунитет роя и иммунитет дома должны совпадать, иначе мост (ADR-0006) трещит:
в дом кровь уходит только под совместимой лицензией (SPEC-0006/SPEC-0009 дома).
Живой факт 2026-11-05: у семи клеток роя лицензий нет вообще (GitHub API,
анонимный лимит; профиль честно говорит о пустых лицензиях) — клетка без
лицензии не может ни принять кровь, ни отдать.

## Решение

Ядро роя — Apache-2.0 (канонический текст, как у дома — ADR-0003 дома).
Клеткам роя — та же броня (шаблон в commons-strengthen/templates-cells).
Донорство в upstream — только по протоколу дома SPEC-0009: дарим по рукопожатию
и тому, кто дарит; CLA-ошейник = донорство запрещено, улучшения живут внутри.

## Альтернативы

- GPL/AGPL на клетки — совместимо по входу, но ошейника у него нет, а единая броня
  проще для одного человека (проверяемость одной матрицей).
- Разные лицензии на клетки — матрица иммунитета размножается без нужды.

## Последствия

**Положительные:** один иммунитет на рой и дом; патентный грант включён.
**Отрицательные / цена:** чужие вклады в клетки требуют DCO-дисциплины.

## Проверяемость

`reuse lint`-совместимая структура не обязательна, но LICENSE-файл обязателен
в каждой клетке; `make licenses` добирает факты живым API с датой.
