# ADR-0006: мост в дом COMMONS — пир по протоколу согласия

Статус: принято · Дата: 2026-11-05

## Контекст

Дом COMMONS (github.com/rtynbirf/commons, прочитан клоном 2026-11-05, v0.51.0,
волна №32) записал грамматику обмена с чужими агентами (ADR-0017): согласие дома —
ConsentGrant (воля Человека, PID 1), согласие второй стороны — PeerManifest,
вердикт поимённый до факта, повторы ключа — записанный исход, отзывы не оживают.
В ADR-0017 сказано прямо: «наружное применение (живой swarm) — когда Человек
заведёт живой обмен с чужими агентами». Рой и есть тот живой swarm — свои клетки
человека. Ограничения дома приняты: локальный транспорт (ADR-0016: stdio,
http-localhost), наружного шлюза нет; кровь — журнал фактов, не pub/sub;
событие без цены недействительно (SPEC-0003).

## Решение

Рой подключается к дому как **пир**, не как орган:
1. Голос роя — `peers/peer-manifest.json`: ровно четыре ключа грамматики дома
   (name, transport, consents, provenance), transport — stdio (скрипты роя
   говорят по stdio на хосте Человека).
2. Согласия роя — `consent/grants.json`: зеркальный белый список методов роя;
   «согласие на всё подряд» — не согласие.
3. Кровь роя — `scripts/emit.py`: конверты SPEC-0003, словарь типов дома,
   хэш-цепочка `prev_id`/`prev_sha256` по канонической форме дома — совместимость
   байт-в-байт (cross-тест в tests против живого клона).
4. Грамматика дома не reimplementируется где попало: одна зеркальная копия в
   `scripts/verify.py`, cross-проверка импортом живого `synapse/consent.py` дома.
5. Рой не вносит себя в реестр органов дома: орган подключается ритуалом
   ADR-0005 дома (живая перепроверка лицензии + живой пульс + приёмка CI).
   Заготовка — `scripts/to_organ_registry.py` со статусом proposal.

## Альтернативы

- Вписать клетки роя в `organs/registry.yaml` сразу — преждевременно: лицензии
  клеток не верифицированы живым API (лимит 2026-11-05), пульса через синапсы нет.
- Связь форком дома — запрещена домом (органы не форкать) и роем (клетки не форкать).

## Последствия

**Положительные:** обе стороны уже говорят одним словарём согласия и одной кровью;
первый живой обмен требует только ConsentGrant от Человека в доме.
**Отрицательные / цена:** двойная грамматика (зеркало) может дрейфовать — лечится
cross-тестом против клона дома в CI роя.
**Обратный мерж:** в дом отправляется аддитивный пакет (см. commons-strengthen):
ADR-предложение реестра пиров, голос роя как данные, приёмка — чистые функции
без сети.

## Проверяемость

`make cross-handshake COMMONS=<клон>` печатает поимённые вердикты обеих сторон.
Тест отключения: без дома рой цел (`make verify`); без роя дом цел — мост
не превращает ни одну из сторон в паразита.
