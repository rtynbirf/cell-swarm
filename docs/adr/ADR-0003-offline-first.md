# ADR-0003: офлайн-first, ядро без SaaS

Статус: принято · Дата: 2026-11-05

## Контекст

Рой — собственность человека, а не подписка. Знание при себе: если клетка не
запускается без чужого сервиса, это не клетка, а паразит (родство с «тестом
отключения» дома — SPEC-0001 G2: выдёрнутый орган не хоронит организм).

## Решение

Ядро роя (геном, скрипты, тесты, согласия) работает на stdlib: clone → make →
работает, без сети. Сеть — только для честного обновления: пины (`git ls-remote`)
и лицензии (GitHub API), всегда с датой и методом; результат попадает в геном
как факт, не как предположение.

## Альтернативы

- CI как обязательное условие работы — клетка мертва без внешнего раннера.
- Облачный реестр генома — знание не при себе.

## Последствия

**Положительные:** рой живёт на суверенном узле (cell65-host); цензуры маршрута нет.
**Отрицательные / цена:** нет облачных индексов и кэшей — поиск по рою локальный.

## Проверяемость

`make verify && make blood-demo && make handshake` проходят с отключённой сетью.
