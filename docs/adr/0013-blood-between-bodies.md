# ADR-0013: Кровь между телами и память роя с допуском (Волна вторая)

- Статус: принято
- Дата: 2026-11-07
- Контекст: воля владельца (такт 2026-11-07, «Волна вторая»): «рой из модели
  в кровь (2 живые клетки через blood-конверт), память роя = файлы с допуском,
  Rust-тропа». Кровь клетки (ADR-0004 в runtime-protocol) жила без живого
  кровообращения: летопись `blood/LEDGER.jsonl` была пуста, второй клетки цепи
  не существовало.

## Проблема

Конверт крови описан, но не течёт: некому открывать пульс, вторая клетка
не приёмник, а статус клетки без явного ожидания не определён (старое ядро
сравнивало чужое ожидание со своим телом и врало бы DRIFT). Память роя
не несёт допуска и провенанса — факт без источника и срока не верифицируем.

## Решение

1. **Межтельная кровь течёт по событию.** Пульс открывает геном
   (`scripts/genome_pulse.py` + workflow `blood-genome`, workflow_dispatch —
   событие, не таймер): конверт прививается к летописи и dispatch первой
   клетке. Цепь: **cell-swarm (геном) → runtime-protocol → polymath-os**
   (терминальная). Эхо клеток — в `blood/LEDGER.jsonl`, append-only,
   хеш-цепь, ttl.
2. **OBSERVED — честный статус клетки без ожидания.** `verdict_for`:
   есть явное `payload.cells[клетка]` — сверка точная (VERIFIED/DRIFT);
   ожидания нет — клетка **наблюдает** чужой факт и несёт свой живой SHA,
   не подставляя чужое ожидание под своё тело.
3. **Тела крови — указатели и vendor-копии с провенансом.** Ядро крови
   передаётся по SHA: приёмник polymath-os несёт `tooling/blood/kernel/`
   с provenance (sha256 источника), ядро в cell-swarm — `blood/kernel/`;
   идемпотентный повтор: конверт, уже лежащий в летописи, — не рана
   (повторная доставка не создаёт ложной сверки).
4. **Rust-тропа.** `runtime-protocol/rust_trail` (ADR-0005 клетки): std-only
   канон + sha256 + envelope_hash; золотые пробы из Python-ядра
   (`tools/make_golden.py`) — Rust повторяет байты ядра байт-в-байт
   (CI `rust-trail`, golden 4/4). Протокол доказан вне одного языка.
5. **Память роя = файлы с допуском.** `memory/MEM-*.json`: строка знания
   несёт допуск (`tol.ttl_days` — сколько факту жить), хеш-цепь (`prev`/`hash`)
   и провенанс (`repo@ref:path + source_sha256`, CONFIRMED живым API).
   `tools/memory_check.py` (`make memory`, CI-хук) — цепь/свежесть/источник
   fail-closed; дрейф = пересверять, не удалять (карта ≠ территория).

## Следствия

- Рой имеет кровообращение: факт тела течёт к телу по событию и проверяем
  по цепи любым, кто умеет sha256.
- Клетку крови можно родить во втором языке — байты совпадут (тропа зелёная).
- Знание роя несёт допуск и источник: просроченное — пересверить, чужое —
  не вставить. Летопись и память только пополняются (Закон 4, храповик).
