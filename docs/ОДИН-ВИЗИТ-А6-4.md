# ОДИН-ВИЗИТ А6-4 — кровная дверь: три руки за один заход в UI

Статус: ждёт руку владельца (никакой агент это сделать не может — PAT и GitHub App
чеканятся только человеком в интерфейсе; API токены не создаёт). Всё остальное
дверь делает сама: после визита диспатч `blood-genome` зелёный = А6-4 закрыт.

## Шаг 1 · конверт B′ → секрет CELL_SWARM_DISPATCH_TOKEN

1. Открыть: https://github.com/settings/tokens/new (classic, **ровно `repo`**, срок —
   до смерти текущего A″ 2026-12-14 или меньше).
2. Скопировать значение.
3. Открыть: https://github.com/rtynbirf/cell-swarm/settings/secrets/actions/new?name=CELL_SWARM_DISPATCH_TOKEN
   → вставить → Add secret.

## Шаг 2 · GitHub App «кровь-геном» → два секрета

1. Открыть: https://github.com/settings/apps/new
   - Имя: `кровь-геном` (или любое свободное);
   - Homepage: https://github.com/rtynbirf/cell-swarm;
   - Permissions: **Contents: Read**, **Actions: Read and write** (больше — ничего);
   - Where can this app be installed: **Only on this account** (rtynbirf).
2. Создать → «Generate private key» → скачается `.pem`.
3. App ID виден на странице App (Settings → General, поле ID).
4. Открыть: https://github.com/rtynbirf/cell-swarm/settings/secrets/actions/new?name=CELL_SWARM_APP_ID
   → значение ID → Add secret.
5. Открыть: https://github.com/rtynbirf/cell-swarm/settings/secrets/actions/new?name=CELL_SWARM_APP_PRIVATE_KEY
   → содержимое `.pem` целиком (включая BEGIN/END строки) → Add secret.
6. Установить App на аккаунт: страница App → «Install App» → только rtynbirf.

## Шаг 3 · переменная-гейт

Открыть: https://github.com/rtynbirf/cell-swarm/settings/variables/actions/new?name=CELL_SWARM_APP_ON
→ значение `1` → Add variable.
(Гейт стоит на переменной, не на секрете: контексты `steps.if` без `secrets.*` —
грабля ×30, startup_failure 43747873231.)

## Шаг 4 · приёмка (одна кнопка)

Открыть: https://github.com/rtynbirf/cell-swarm/actions/workflows/blood-genome.yml
→ «Run workflow» → main → Run.
Зелёный прогон = А6-4 закрыт; дверь сама перешла на короткие App-токены (А6-1 активна),
конверт B′ остаётся фолбэком.

## После визита

Напомнить дому обычным словом (любой агент внесёт закрытие в РЕЕСТР index,
HOUSE_STATE khozyain и ворклог PHOENIX — TH-запись следующего такта).
