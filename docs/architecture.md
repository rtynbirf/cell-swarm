# Архитектура роя — развёртка пяти законов

Аксиома: топология репозиториев повторяет память работающего. У агента — окно
контекста, у человека — рабочая память. Отсюда пять законов (обоснования — ADR-0001..0005):

1. **Клетка** — автономность. Четыре органа: ДНК (`MANIFEST.json`), мембрана
   (`README.md` + `AGENTS.md` + `llms.txt`), метаболизм (`Makefile` + скрипты),
   тело (геном, голос, согласия, кровь, ADR). Проверка: clone → make → работает, офлайн.
2. **Окно** — митоз по боли контекста: файл → папка → репо. Граница репо = граница
   контекста (ADR-0001).
3. **Указатели** — пины в геноме, не импорты (ADR-0002). Хаб хранит магниты.
4. **Храповик** — тесты и ADR только добавляются; решение фиксируется до кода.
5. **Семя** — `bootstrap.sh` поднимает рой из генома (ADR-0002, ADR-0003).

## Карта ядра

```
cell-swarm/
├── MANIFEST.json          # ДНК ядра
├── swarm.json             # ГЕНОМ: клетки + живые пины + мост
├── peers/peer-manifest.json   # голос роя для дома (ADR-0017)
├── consent/grants.json    # согласия роя (зеркало ConsentGrant)
├── blood/journal.jsonl    # кровь роя (создаётся emit.py)
├── scripts/               # метаболизм: verify, handshake, emit, pin, to_organ_registry
├── docs/adr/              # храповик решений
├── tests/test_swarm.py    # приёмки грамматик + cross против дома
├── templates/             # шаблоны новой клетки (митоз)
├── bootstrap.sh           # семя
└── Makefile               # вход
```

## Границы клеток (Закон 2 в действии)

| Клетка | Что держит | Мост |
|---|---|---|
| cell-swarm (ядро) | геном, согласия, кровь | → дом COMMONS (ADR-0006) |
| polymath-os | слои самосбора | substrate роя |
| singulyar-llm | локальный инференс | метаболизм |
| singulyar | корпус данных | память |
| cell65-host | нода-хост | substrate |
| rumu | P2P-просмотр | сенсорика |
| voice-atlas-llm | голоса | сенсорика + consent |
| global-video-platforms-registry | указатели платформ | genome-реестр |

Системные имена — `system_pre` в геноме: словарь дома, заявленные кандидаты на
ритуал ADR-0005 дома, не свершившийся факт.

## Обмен с домом (коротко)

```
рой ── PeerManifest (4 ключа) ──→ дом читает
дом ── ConsentGrant (воля Человека) ──→ вердикт до факта
обмен ── конверты SPEC-0003 с cost ──→ кровь append-only, хэш-цепочка
```

Наружного шлюза нет: обмен живёт на хосте Человека (stdio/http-localhost).
